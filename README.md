# BMI Calculator

A simple and user-friendly **BMI (Body Mass Index) Calculator** built using HTML, CSS, and JavaScript. This project allows users to calculate their BMI by entering their height and weight and displays their corresponding BMI category.

## 🚀 Features

- Simple and clean user interface.
- Enter height in centimeters (cm).
- Enter weight in kilograms (kg).
- Calculate BMI using the standard BMI formula.
- Display BMI value up to two decimal places.
- Show BMI categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Input validation for empty, zero, and negative values.
- Reset button to clear inputs and results.
- Responsive design for mobile and desktop screens.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure.
- **CSS3** – For styling and responsive design.
- **JavaScript** – For BMI calculation and input validation.

## 📐 BMI Formula

BMI is calculated using the following formula:

```text
BMI = Weight (kg) / Height (m)²
```

Example:

- Weight = 60 kg
- Height = 170 cm (1.70 m)

```text
BMI = 60 / (1.70 × 1.70)
BMI = 20.76
```

**Result:** Normal Weight

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in your web browser.
5. Enter your height and weight.
6. Click the **Calculate BMI** button.
7. View your BMI result and category.
